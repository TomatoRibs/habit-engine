# 陪你改掉一个总也坚持不下来的习惯

说一句「我想每天跑步，但总是跑两天就停」，它不会给你一张计划表。

它先问你上次是怎么断的，再把这件事拆成今晚就能做完的一件小事。之后四周，它每天问你一句，按你的实际情况改方案。

> 不给道理，只给能发生的变化。

`不用编程` · `不用注册` · `不上传` · `不收费` · `装完就能用` · MIT

急着装？直接跳到 [怎么装](#怎么装)。

## 为什么做这个

AI 越来越快了。模型一天比一天聪明，agent 一秒能跑几十步。

但我们的日常没变：想减肥，还是没动；想学习，还是在打游戏。

问题从来不是你不知道该怎么做。是知道的那一刻你有，要动手的那一刻你没有。

市面上的习惯产品，全都停在「给你一套方法」，然后就结束了。三天后你回到原样——你缺的从来不是方法，是有人在中途按你的实际情况改一版。

所以我把「中途改方案」这件事做成了流程：三本主书打底（《原子习惯》《习惯的力量》《认知觉醒》），按场景再调另外三本（《影响力》《思考，快与慢》《福格行为模型》），37 个场景、三个阶段八个步骤，全部写死进流程里。

它不以书为骨架。入口永远是你当下卡在哪一步，书是被这一步临时叫来的原料。

## 你会得到什么

不是「一份计划」，是四样东西，而且当天就能拿到：

| 时间 | 会发生什么 |
|---|---|
| 第一次聊完 | 你知道自己上次为什么断了，手上有一份今晚就能做的动作清单 |
| 当天晚上 | 环境和摆法改好了，拍张照片就算过关 |
| 第二天 | 有一个人、一笔押金在管你，你有一张截图 |
| 之后每天 | 一句问候，你回两个数字：做没做、有多难 |
| 第 7 天 | 它第一次给你改方案，不是你求它改 |
| 第 28 天 | 要么加点难度，要么收案 |

三段走完，你手上是：**一句关于自己的判断、一张摆好的照片、一张转账截图、一个你自己挑的时间。**

它不承诺你多久见效。这一点写在免责里，不藏在末尾。

## 你可以直接说这句

装好之后随便挑一句，改成你自己的情况发过去：

- 「我想每天自己做饭，但总是坚持几天就断了。」
- 「我知道该早睡，就是一躺下就刷手机，停不下来。」
- 「每天下班到家九点多，还想跑步。我知道该跑，就是不动。」
- 「三个月前公开立的 flag，现在完全不想动了。」
- 「我想戒掉每天一杯奶茶，试过一次没成。」

它不会问「你的目标是什么」。第一句问的是：**「这事你以前试过几次？」**

就这一句，决定了它从哪儿开始——从零搭、是找卡在哪一步、还是翻你上次的旧账。

## 它不解决什么

- **需要看医生的问题。** 抑郁、焦虑、ADHD、睡眠障碍、物质依赖——它一发现就停下来，让你走专业路径，不给行为方案。这不是客套，是写死在流程里的第一道闸门。
- **结构性的困境。** 「这份工作每天干十二小时」这类，它插不进去，能做的只是在缝隙里插一根针。
- **一次性的事。** 整理房间、搬家、写毕业论文——那不是习惯，它只给一个启动动作就结束。
- **替你动手。** 消息得你自己发，押金得你自己转，东西得你自己挪。

边界说清楚，比多承诺一条功能有用。

## 它怎么管住你

三段，一段做完再做下一段。不是给你一张 21 天计划表。

| 段 | 它干的事 | 说人话就是 |
|---|---|---|
| 第一段 · 铺开 | 把「我想减肥」拆成今晚十点前能做完的两三件小事，再把东西摆到你必经的路上 | 让「开始」这件事不用下决心 |
| 第二段 · 押注 | 找一个每周会问你一次的人，押一笔真会出去的钱 | 自己盯自己，是最没用的一种 |
| 第三段 · 追踪 | 每天问你一句：做没做、有多难（0–10 分） | 它拿这个分数看你卡在哪，不是给你打分 |

之后四周它按你的申报调：你说今天不想动，它把动作砍一半，而不是让你再挺一挺。第 3、7、14、21 天各正式调一次，第 28 天要么加点难度，要么收案。

**收案的标准不是坚持满多少天**，是两条：不做会难受，断了能自己接回来。

## 它见过的情况

37 个高频场景，八类。你大概能在里面找到自己那一句：

| 类 | 它接得住的话 |
|---|---|
| 身体与运动 | 跑步总跑两天就停 · 想减肥 · 想练肌肉 · 生完孩子想恢复 · 一周健身三次 · 骑车上班不坐地铁 |
| 睡眠与手机 | 想早睡躺下就刷到一点 · 想六点起 · 睡前手机放不下 |
| 戒断 | 戒烟一天一包 · 每天都喝酒 · 戒奶茶 · 戒游戏刷短视频 |
| 学习与技能 | 想学英语 · 想考证 · 学一阵就停 |
| 生活与关系 | 想整理家 · 想陪孩子读书 · 想跟家里人多说两句 |
| 工作与产出 | 想写东西 · 想早收工 · 一到下午就没劲 |
| 情绪与记录 | 想每天记一笔 · 一有情绪就吃点东西 |
| 特殊状态 | 出差多 · 带娃 · 换工作 · 生病之后 |

每一类都写清了「动作怎么剥、哪一步会翻车」。比如「骑车上班不坐地铁」那一条，它不会给你定「每天骑车锻炼」，而是剥成「早上出门骑去公司」，外加把打车软件挪到第二屏、车停到出楼门第一眼看见的位置——因为翻车点从来不在意志，在车停在角落你懒得走过去。

> 戒断那几类要说清楚：烟、酒、安眠药这类有生理依赖的，它只做减量，加一道摩擦，并且劝你去看医生。硬断有身体风险，它不接。

## 它说话长什么样

下面是一个真实跑通的案例。用户想每天自己做饭，坚持过三个月，断在长期出差和谈恋爱。

**你说：** 我想每天自己做饭。之前其实坚持了三个月，后来断了。

**它：**

> 三个月，那不算没毅力。
>
> 先问你三件事，别急着定方案：
>
> · 以前为这件事做过什么，买过什么锅、囤过什么菜，都算？
> · 最长一次坚持了多久？
> · 上一次停下来，是因为什么？

**你说：** 锅具都齐。坚持了三个月，后面断是因为长期出差不方便，另外谈了对象，很多时候就想出去吃。

**它：**

> 那你上次不是毅力问题。
>
> 你原来那套是给「一个人、天天在家」设计的。现在你长期出差、还多了个女朋友，那套方案的每一环都失效了——出差没厨房，去她家不用你做饭。
>
> 场景换了，方案没跟着换。这是你上次真正的死法。

然后是那一块必须讲专业的地方——它会告诉你这是哪本书里的哪个方法，不装自己编的：

> ▍《福格行为模型》中的行为发生条件
> 该模型提出，行为的发生需要动机、能力、提示三者同时具备。
> 动机，指的是当下的意愿强度；能力，指的是完成该行为的难易程度；提示，指的是触发该行为的外部线索。
> 对照本例：动机稳定，不缺；一个半小时、厨房就在家里，能力够但成本偏高；缺口在提示——七点多进门那一刻，没有东西把行为引向厨房。
>
> 因此本次不动动机，只动提示与阻力。

讲完才给动作，而且是今晚十点前能做完的：

> 今晚十点前，两件事：
>
> 一、【冰箱里现在的菜全部洗好切好，一袋装一顿，分开装】
>
> 二、【空饭盒拿出来，放灶台边上，不收回柜子】
>
> 便签写这一句，贴厨房门框，进门第一眼看得见：「我放下包走进厨房，先接一锅水烧上。」
>
> 不写「我要做饭」。烧水不用做决定，水开那几分钟你正好切菜。

到第 7 天，它调方案长这样——三句，加一个决定，不给你看表格：

> 你七天里报了六次，做了四次。两次没做都在周三周四，那两天你有会。
> 所以把周三周四改成中午走十分钟，其他天不动。

**它不会做的几件事：**

- 不说「坚持」「自律」「战胜自己」——这些词把失败归到人格上，而人格改不了。
- 不说「21 天养成一个习惯」——这句话没有研究支持。
- 不一上来给方案。第一句永远是问，而且只问一件事。
- 不问「你想找谁」再等你一轮。名字不是问出来的，是直接给你动作，让你在动作里自己定。
- 不把押金写成定数。「转他两百」这种话它不说，两百只是建议，数字得你自己报。

## 怎么装

### 方式一 · 不打开终端，四步（大部分人用这个）

1. 在这一页找到绿色的 **`Code`** 按钮 → 点 **`Download ZIP`**。
2. 解压。解压出来的文件夹可能叫 `habit-engine-main`，**把它改名成 `habit-engine`**（这步别省，名字不对就认不出来）。
3. 随便打开一个文件夹窗口，把下面这行**粘进最上面的地址栏**，按回车：

   ```
   C:\Users\你的名字\.workbuddy\skills
   ```

   把 `你的名字` 换成你自己的 Windows 用户名。macOS / Linux 用 `~/.workbuddy/skills`。

4. 把改名后的 `habit-engine` 整个文件夹拖进去，重启 WorkBuddy。

然后说一句「我想每天跑步，但总是跑两天就停」，它就接上了。

> **看不到 `.workbuddy` 是正常的**——它是隐藏文件夹。不用去改「显示隐藏文件」的设置，把路径粘进地址栏就能直接进去。
>
> 解压后多出来的 `README.md`、`TESTS.md`、`CHANGELOG.md` 不影响使用，不用删。

### 方式二 · 什么都不装（装不上就走这条）

没有 WorkBuddy、或者懒得动文件夹，也能用。

打开仓库里的 `SKILL.md`，全选复制，粘进任何 AI 的对话框，末尾加一句：

> 按这个流程陪我改一个习惯：我想每天读书，但一看手机就忘了。

纯文字，不用插件、不用账号。**它退了半步，但流程还在**——翻旧账、拆动作、收押金、每天问一句，这些都写在 `SKILL.md` 里。

### 方式三 · 一行命令（给习惯终端的人）

```bash
git clone https://github.com/TomatoRibs/habit-engine.git ~/.workbuddy/skills/habit-engine
```

## 你现在用的方式，换成它会不一样在哪

| 你现在用的 | 它不一样的地方 |
|---|---|
| 打卡 App、连续天数 | 它不数你连了几天。断了第一句是「上次断在哪」，不是「你已中断 3 天」。 |
| 那种「断了不清零、分数慢慢衰减」的记分 App | 它连分都不记。断了就问什么变了，然后把方案改掉——分数衰减只是让你不那么难受，方案不改，第三天照样断。 |
| 待办清单、日程表 | 它不给你一列任务，一次只让你做今天这一件。 |
| 自律群、监督 App | 它不催你。你连着两次说不想动，它把动作砍一半，而不是让你再挺一挺。 |
| 书、播客、课程 | 它不讲完道理就结束。每段道理后面必须跟一个你今天能做完的动作。 |

最根本的区别只有一件事：**别人给你一套方案，它在四周里按你的实际情况改方案。**

## 你的数据在哪

- 记录写在你自己的电脑上：`<你的工作目录>/.workbuddy/habit-engine-state/`。不写进 skill 本身。
- 仓库里没有任何网络请求，不需要账号，记录不上传。
- 闸门命中时只记「判定结果」，不记你说的具体症状——存档不该变成病历。
- 押金那笔钱是转给你自己找的人，跟这个工具无关，它只管提醒你。

## 免责声明

这不是临床工具。抑郁、焦虑、ADHD、睡眠障碍、物质依赖请走专业路径，遇到这类情况它会停下来转介。

它引用《原子习惯》《习惯的力量》《认知觉醒》等书的方法，也在文档里标了这三本书各自的盲点。但机制层——四周调参、阻力分——目前只有设计依据，**没有真人效果数据**；不承诺「照做就有效」，也不承诺多久见效。

## 给愿意动手的人

这段可以跳过。两条命令能看出它是不是真做到了自己说的事：

```bash
python3 scripts/check_skill.py --strict       # 包规范 17 条，警告也算失败
python3 scripts/check_message.py <消息文件>   # 消息格式 14 条
```

当前这版跑下来是 17 条全过、0 警、0 败。`TESTS.md` 里记了六轮测试，也写清了证明不了什么。
