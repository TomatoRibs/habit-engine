# 01 · 闸门与卡点诊断

本文件负责一件事：**在给任何建议之前，把这个人的卡点定到某一层，并确认他没有需要先转介的情况。**

顺序不可跳。G0 没过，后面一律不谈。

---

## G0 · 硬闸门（临床指征，命中即停）

### 判定项

| 项 | 判据 | 说明 |
|----|------|------|
| 情绪 | 持续低落、兴趣丧失，且**超过两周** | 两周是抑郁发作的通行时长门槛，不是我们编的 |
| 兴趣 | "连以前喜欢的事都提不起劲" | 这一句单独权重很高。享乐也需要动机时，问题不在这一件事 |
| 睡眠 | 长期入睡困难、早醒、或睡眠需求显著增多 | 与"最近熬夜"要分开，问时长 |
| 食欲 | 显著变化，暴食或厌食 | 同上，问时长 |
| 注意 | 长期、跨场景、**从小就有**的无法专注 | 三个条件都满足才提示 ADHD 方向；只满足一两个不要提 |
| 弥漫性 | 无法启动**持续六个月以上**，换过多个目标都一样 | 单目标失败不算；换什么目标都启动不了才算 |
| 风险 | 任何自伤、自杀相关表述 | 零容忍，任何暗示都要停 |

### 命中后怎么说话

先接住，再转介，不给方案。三步：

一、接住，不评判：「你说的这个状态，听起来已经不只是习惯的问题了。」

二、说明为什么停：「这类情况有它自己的处理路径，行为技巧对它的效果很有限。我不想给你一套做不动的方案，那只会让你觉得又是自己的问题。」

三、给出方向，不诊断：「先去做一次专业评估，比我们再调动作有用。」

### 说话禁忌

- 不说"你有病""你这是抑郁症"
- 不说"我帮不了你"（不是拒绝，是换路径）
- 不说"可能只是压力大"（把临床指征轻描淡写）
- 不继续问细节去"确认诊断"（我们不是评估工具）
- 不要在转介后仍给"顺便说一下你可以试试…"

### 转介后的存档

记录到使用者的工作区（`<cwd>/.workbuddy/habit-engine-state/`，**不写进 skill 包**）：判定为 G0 命中、日期、触发项、已转介。**不记录具体症状细节**，只记判定结果，避免存档变成病历。

## G0.5 · 物质依赖闸（不是停，是改方向）

G0 管的是「先别做方案」，这一道管的是「方案只能这么写」。

### 判定项

问一句：「有没有每天不来一口就过不去的东西，烟、酒、安眠药、止痛药？」

命中任意一条就进本闸：

- 每天固定量，断一天就烦躁、手抖、睡不着
- 以前试过突然停，出现明显的身体反应
- 靠它才能入睡或才能工作

### 为什么单独设一道

这类行为突然停有**身体风险**（酒精戒断可致癫痫，镇静类药物戒断可致抽搐），不是意志问题，也不是习惯设计能覆盖的范围。

同时它和普通习惯的机制不一样：减行为要靠替代物加环境移除，而依赖状态下的替代物很难顶住生理驱动。

### 命中后怎么说话

三步，不许省：

一、**不吓他**：「这个跟跑步不一样。突然停身体会有反应，靠硬扛反而危险。」

二、**只给减量，不给断**：「我能帮你把每天的量往下压，也能帮你把触发它的场景拆开。彻底停这一步得医生陪你走。」

三、**给一个具体的第一动作**：不是「少抽点」，是「把烟从客厅挪到阳台，抽之前必须站起来走过去」。加一道摩擦，不减少数量——数量留到他能控的时候再谈。

### 禁忌

- 不给「明天开始一根不抽」「21 天戒断计划」
- 不说「戒不掉是因为你不够想」
- 不因为他说「不用找医生」就改成给断的方案
- 他明确拒绝就医时，只做减量和场景拆分，并说清「到这一步我只能帮到这儿」

## L0 · 软能量层（非临床，但处方要降级）

G0 没过，但用户处在高压、连续加班、生病恢复期、睡眠不足的状态。

这一层不是闸门，是**降级开关**：所有处方降到保底档。

| 状态 | 处方调整 |
|------|---------|
| 睡眠不足 / 生病恢复 | 只给保底动作，不给今日行动；明确说"这周不算数，只求不断" |
| 连续高压（截止日、家事） | 动作砍到 30 秒级；取消一切加量；允许暂停并写死重启条件 |
| 环境剧变（搬家、换工作、新生儿） | 不设计新习惯。只维护一条已有的最低线 |

判停条件（满足即停，不许硬推）：

- 用户说"我现在什么都不想弄" → 停，不劝
- 同一条保底动作连续三轮仍未做 → 不是意志问题，是能量问题，回查 L0

## L1 · 任务层（行为本身的形状有问题）

### 诊断问句

只问这些，一次问一到两个：

- 你要做的这件事，具体是哪个动作？（"运动"不是动作，"铺开垫子"才是）
- 你能不能用一句话说出"做完了"是什么样？
- 做完之后，多久能看到任何变化？
- 这件事本身，有没有任何一点是你自己想要的（不是应该做的）？

### 四种卡点

| 卡点 | 表现 | 本质 | 去哪 |
|------|------|------|------|
| 模糊 | 说得出领域说不出动作 | 没有启动点，到点还要现想 | 砍到物理动作 |
| 过大 | 动作存在但一次要做很久或很多 | 启动成本高于当下能量 | 砍到 2 分钟版 |
| 反馈太远 | "做了也看不出来" | 奖励延迟，行为无法被强化 | 造即时可见的痕迹 |
| 无内在价值 | "纯粹应该做" | 全靠外部压力驱动，压力一撤就停 | 换形式或换目标 |

### 操作细节

**砍到物理动作**：把"运动"翻译成"穿上跑鞋""铺开垫子""走到楼下"——标准是这个动作**别人能看出你做了没有**。"想了一下"不算动作。

**造即时痕迹**：不是打卡 App（那是外部监督），是可感知的物理痕迹——日历上画一道、书页折角、瓶子挪位置。要求是做完之后环境有变化。

**判停条件**：如果砍到 30 秒版用户还说"做不到"，问题不在任务层，往下走 L2。

---

## L2 · 情绪层（事情本身让他不舒服）

### 诊断问句

- 想到这件事的时候，身体有什么感觉？（紧、闷、想逃、烦）
- 如果保证没人会知道，你还做吗？
- 这件事有没有哪一部分让你觉得自己被评判？
- 你是怕做不好，还是怕开始？

### 四种卡点

| 卡点 | 表现 | 本质 | 去哪 |
|------|------|------|------|
| 任务厌恶 | "一看就烦" | 行为与负面体验绑定 | 换形式 / 绑定愉悦 |
| 完美主义 | "要么做好要么不做" | 标准高于当前能力，启动即失败 | 设一个"允许难看"的版本 |
| 身份威胁 | "做这个显得我很差" | 行为与自我形象冲突 | 建立新身份叙事（不用口号） |
| 恐惧评价 | "别人会笑话我""已经公开说过了" | 社会评价压力 | 《影响力》承诺一致 + 降低公开度 |

### 操作细节

**恐惧评价 / 已公开立 flag**：这一格是本 skill 唯一高频跨书调用的地方。核心不是"别在意别人看法"（没用），而是把承诺的**内容**改掉——从"每天跑"改成"每周三次"。公开承诺的力量在于一致性压力，改内容比撤承诺阻力小得多，且能兑现。

具体三步：
1. 承认这个 flag 现在变成了负担，不劝他"既然说了就做到"
2. 把承诺降级成能兑现的版本，并在同一个渠道说明调整（一致性保住，压力解除）
3. 新承诺的第一次必须极小，确保兑现

**完美主义**：给一个明写的"难看版"标准，比如"允许只做 30 秒且姿势随便"。关键是把"低标准"合法化，否则他连开始都不肯。

**判停条件**：如果情绪层的卡点是"身份威胁"且涉及深层自我评价（"我这个人就是不行"），不要在这个 skill 里深挖，那属于更深的工作。给动作，不给解释。

## L3 · 环境层（外部结构让行为无法发生）

### 诊断问句

- 这件事要在哪儿做？那个地方现在是什么状态？
- 你打算什么时候做？那个时间点你通常在干什么？
- 你要用的东西，现在离你多远？
- 你有没有试过"到点了但还在做别的事"？

### 四种卡点

| 卡点 | 表现 | 本质 | 去哪 |
|------|------|------|------|
| 启动摩擦高 | 要准备、要找、要换衣服 | 每多一步，概率掉一截 | 提前布置，摩擦清零 |
| 诱惑太近 | 手机在手边、沙发在旁边 | 竞争者距离更短 | 物理隔离，不靠自控 |
| 无锚点 | "打算晚上做" | 绑在时间点而不是已有行为 | 换成行为锚点 |
| 决策疲劳 | "到点了还要想做什么" | 每次启动都要重新决策 | 写死动作，不留选择 |

### 操作细节：锚点怎么选（本 skill 最核心的操作件）

**锚点必须是已有行为，不是时间**。

错：晚上 9 点运动（9 点不是行为，是一个数字）
对：坐到沙发之前（"坐沙发"是每天必然发生的行为）

选锚点的三个标准：
1. **每天必然发生**（刷牙、倒水、进门换鞋、坐到某个位置、打开电脑）
2. **时间可预测**（误差在半小时内）
3. **紧邻**（新动作接在它前后，中间不隔其他事）

关键洞察（来自真实案例）：**如果一个动作需要两次启动，它就不会发生**。比如"坐到沙发上再起来运动"，实际要求一晚启动两次——第一次是坐下，第二次是起来。正确做法是把锚点放在"坐下之前"，让新动作只需一次启动。

**判停条件**：换过两个锚点仍然做不到，问题不在锚点质量，回查 L2（是不是根本不想做）。

## 诊断决策树（一张图看完）

```
用户来了
  │
  ├─ G0 硬闸门命中？ ──是──> 转介，停止，不给方案
  │                    否
  │                     ↓
  ├─ 有具体行为吗？
  │    ├─ 没有 ────────────> 设计线（走 02-routing 九格）
  │    ├─ 有但做不到 ──────> 启动线
  │    │      ├─ L0 软能量层（高压/病中）→ 只给保底动作
  │    │      ├─ L1 任务层 → 砍形状
  │    │      ├─ L2 情绪层 → 处理不适
  │    │      └─ L3 环境层 → 改结构 + 选锚点
  │    └─ 有过但断了 ──────> 修复线（走 02-routing 修复格）
  │
  └─ 说不清 ──> 只问一句（三选项），然后重新进树
```

## 一个常被搞错的地方

四层不是"从低到高"，也不是"一层一层全查一遍"。它们的正确用法是：

**先查 L1，因为任务形状最容易改**；L1 改完还不行，查 L3，因为环境比情绪好动；L3 改完还不行，才是 L2。

L2 放最后不是因为不重要，是因为它最贵——处理情绪需要用户愿意谈，而大多数人一开始不愿意。先把便宜的两层改掉，很多时候问题就没了。

但如果用户一开口就是"我怕别人笑话""我觉得自己不行"，直接进 L2，别绕。
