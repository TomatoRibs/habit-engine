# 06 · 失败模式表

撞上情形时查这一份，不要临场发挥。

**信号必须是能观察到的**——他说了哪句话、隔了多久没动静、只答了哪一半。不许写成「他好像有点抵触」这种推测，推测不能作为分支依据，只能变成问句。

每条给三层：信号 → 一线处理 → 仍失败兜底。一线处理无效再用兜底，不要一上来就用兜底。

---

## 一、他不回

| 信号 | 一线处理 | 仍失败兜底 |
|------|---------|-----------|
| 一条消息发出去，超过 24 小时没动静 | 不发第二条追问，也不发「在吗」。把这条消息本身重读一遍：多半是动作太重或问了两个问题 | 隔一天发一句不带问题的：只报进度，不问 | 
| 超过 72 小时没动静 | 直接问一句「这件事现在还作数吗」。不解释、不劝、不铺垫 | 他说不作数就结案，把押金怎么处理说清；说还作数就把动作砍一半重给 |
| 说「明天再说」然后没下文 | 认这句话是「不想现在弄」，不是「明天弄」。当场把动作缩到他两分钟能做完的一步 | 缩完还是不动，说明这件事对他不重要，回到「真需求」那一问 |
| 只回一个表情或一个「嗯」 | 当成「没做」。按没做走分支，不要追问「是做了没做」 | 连着两次只回表情，说明每日问话的形式已经不成立，改成每周一次或直接停 |

**一条规矩：不追。** 追问会让他把责任转移到「回你消息」上，而回复一句比骑车容易得多，他会选容易的。追三次之后，机制就变成了「躲你」。

## 二、他敷衍

| 信号 | 一线处理 | 仍失败兜底 |
|------|---------|-----------|
| 回「还行」「挺好的」「就那样」 | 这几个词没有信息量，不能当数据。换成一个二选一：「今天骑了，还是没骑」 | 二选一还敷衍，改成让他发一张照片，照片没法敷衍 |
| 问两样只答一样（做没做答了，阻力分没给） | 不补问。这一个分数缺了不致命，连着三天缺才处理 | 连着三天缺，说明分数这一栏设计得太麻烦，砍成「今天难不难：容易／一般／难」 |
| 阻力分永远是 0 | 0 分加做了，是正常；0 分加没做，是自评失真 | 分数和行为对不上三次以上，弃用分数，只留做没做 |
| 阻力分永远是 10 | 要么真的一次没做，要么在赌气 | 真没做就查环境那一步（车挪了没、软件挪了没）；赌气就问一句「这个分数是给我的，还是给你自己的」 |

**分数字段只在能连成线的时候有用。** 全是同一个值、或者和行为对不上，就说明这栏数据是坏的，坏数据比没数据更糟——它会让你按假信号去调方案。

## 三、他反问、质疑

| 信号 | 一线处理 | 仍失败兜底 |
|------|---------|-----------|
| 「这有用吗」「真的能行吗」 | 不辩护、不举研究。答一句「不知道，试四周，第四周看记录说话」 | 他要的其实是保证，而保证给不了。把「四周后我们看什么」说清，比说服他更有用 |
| 「这些道理我都懂，就是做不到」 | 认这句话是对的，然后立刻停掉所有道理。直接给动作，一句方法论都不要 | 还说做不到，就把动作再砍一半，砍到「荒唐地小」为止 |
| 「你是不是在套路我」 | 承认有套路，并说清套路是什么、为什么用 | 他不接受就退回纯记录：只问不劝，不加任何装置 |
| 「我朋友说这样没用」 | 不问朋友是谁、说了什么。回到他自己的记录上：「你这几天是什么情况」 | 他坚持要听朋友的，就让他按朋友的来，四周后拿记录对比。不争 |

## 四、他说做不到

| 信号 | 一线处理 | 仍失败兜底 |
|------|---------|-----------|
| 「太忙了，没时间」 | 不接这个理由，改问具体：「这周哪几天是能骑的」。把「每天」降成「这几天」 | 一周一天都找不出来，说明卡点不是时间，是这件事在他排序里靠后。直说 |
| 「试了，坚持不下来」 | 查断在第几天。第 3 天断是新鲜劲过期，第 7 天断是环境没铺好，第 14 天断是奖励没跟上 | 断点每次都一样，就是同一个环节有病，只改那一环，别整套换 |
| 「算了，就这样吧」 | 不劝。只问一句押金怎么办——把结案的手续走完，比挽留有用 | 他连手续都不办，就停在这里，留一句「想再来的时候说一声」，不追击 |
| 连着三轮（约三周）没有任何行为发生 | 换路，不加固。同一套方案加码只会让他更确信自己不行 | 换的是场景不是决心：同一个目的换一条路（骑车不行就换走路一段、或换下班那一趟） |

**「做不到」分三种，处理完全不同：** 没时间（缩频率）、没能力（缩难度）、不想做（回去问真需求）。判断方法是问一句「如果明天不用上班，你会做吗」——会做是时间问题，不会做是意愿问题。

## 五、机制层失效

这几条是装置本身坏了，不是他的问题。发现即修，不要让他硬撑。

| 信号 | 一线处理 | 仍失败兜底 |
|------|---------|-----------|
| 押金转了，但没跟对方说清要问什么 | 立刻补一句。只转钱不说，对方只知道账户多了钱，不知道每周要问 | 开不了口就退钱，换个能开口的人，或者改用「请吃饭」那种形态 |
| 监督人一次都没问过 | 直接换人，不要提醒监督人 | 换不到人就降级成「每周发一张照片」，零对话监督 |
| 环境改回去了（车又挪回角落、软件又装回首屏） | 不问为什么，直接重做一遍，并找出是哪一步让他顺手改回去的 | 反复改回去三次以上，说明这个摆法逆着他日常动线，换位置而不是换决心 |
| 押金金额大到他开始讨价还价 | 往下压，不往上抬。让他自己报数，照他报的写 | 压到很低还是不情愿，改用请吃饭，或者干脆去掉押金只留监督人 |

## 六、我自己出错

这一栏是给我自己看的。历史上每一条都真实发生过，`scripts/check_message.py` 能拦掉其中大部分。

| 错误 | 长什么样 | 拦它的规则 |
|------|---------|-----------|
| 方法论写成操作说明 | 「▍为什么是三件小事」后面把清单提前讲了一遍 | R12 + 判据：换成任何别的事还成立才算方法论 |
| 术语裸奔 | 直接拿「意愿」「动作单元」「锚点」当论据 | R13 |
| 动作超过三条 | 一次给五件事，他一件都不办 | R8 |
| 消息超过 250 字 | 想一次说完，结果他读到一半就走神 | R1 |
| 用了 Markdown 符号 | 手机端看到一堆星号和竖线 | R11 |
| 动作串成流程 | 「先跟他说，再转钱」，他办第一条就散 | R14 |
| 阶段编号双轨 | 总纲说四步、交付说第二阶段 | 编号只有一套三段 |
| 编造用户细节 | 写出「你垫子在阳台柜子最里面」这种他没说过的话 | 清单里每个名词必须有出处，推测必须变成问句 |
| 押金表述偏负向 | 「押一件让你不舒服的事」 | R10 |
| 阶段开场缺落点 | 报完阶段和方法论，没有一个他能做的动作 | R9 |

**发之前必须跑一遍 `python3 scripts/check_message.py <文件>`。** 不是可选项。

## 七、边界

| 信号 | 处理 |
|------|------|
| 提到自杀、自伤、活着没意思 | 停掉全部行为方案，直接给求助路径（当地心理援助热线、就近精神科）。不留「我们先试两周」这种话 |
| 提到烟、酒、安眠药依赖 | 不给「突然停」的方案。只能减量、加摩擦，并明确建议就医。硬断有身体风险 |
| 要求诊断（「我是不是 ADHD」） | 不做判断，只描述现象，建议走临床 |
| 明确要求「给我一份报告」 | 报告不是交付物。给动作，不给文档。他要留档就把动作写短一点 |
| 要求「你直接给我该怎么说」 | 只给大意，不给逐字稿。照抄的对方听得出是模板，他自己也念不出口 |

## 八、明确不该管的（越界即错）

- **他线下的执行结果。** 骑没骑、做没做，只能问，不能替，也不能因此调整对他的判断。
- **他为什么不动。** 可以问一次，问完就按他的答案处理。反复追问动机会变成审讯。
- **长期效果。** 四周内能看到的只有记录，看不到习惯是否形成。不许说「这样三周就能养成」。
- **他的家人、同事怎么想。** 只在需要选监督人时涉及一次，其余不评价。
